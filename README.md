# Zirui Li Academic Homepage

This is a lightweight static academic homepage for local preview and future GitHub Pages deployment.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static server.

## Structure

- `index.html` contains the page shell and sections.
- `css/site.css` contains the visual system and responsive layout.
- `js/content.js` stores editable profile, publication, news, honor, and skill content.
- `js/app.js` renders the content, grouped CV sections, folded publications, and dark mode.
- `assets/` contains the public CV, images, papers, certificates, and slides.

## Privacy

The public page and downloadable public CV intentionally omit sensitive personal details. Contact is limited to the two approved email addresses and academic links.
